# 🐢 Turtle Crossing Game

A fun arcade-style crossing game built using **Python** and the **Turtle graphics** module.  
The goal is simple: help the turtle cross the road while avoiding speeding cars.

As the game progresses, the traffic gets faster, making survival a lot harder than it looks 👀

---

## ✨ Features

- Built completely with Python Turtle graphics
- Smooth player movement
- Randomly generated traffic
- Increasing game difficulty and speed
- Score/level progression system
- Simple and clean arcade-style gameplay

---

## 🛠️ Tech Stack

- Python
- Turtle Module
- Object-Oriented Programming (OOP)
